
# CampusClaw

> 面向班级教学场景的智能知识库与学习助手

CampusClaw 是一个基于 Flask 和 RAG（检索增强生成）技术开发的 Web 应用，面向教师与学生提供课程资料管理、班级知识检索和智能问答服务。

系统以班级课程资料为知识来源，结合全文检索与大语言模型生成回答，并提供引用来源，帮助学生快速查找和理解课程知识，同时支持班级级别的数据隔离与权限管理。

## 一、核心功能

### 1. 用户与班级管理

- 支持教师、学生两类用户登录
- 根据用户身份和所属班级控制访问权限
- 不同班级的资料、检索结果和问答上下文相互隔离

### 2. 课程资料管理

- 支持教师上传、查看和管理课程资料
- 支持 Markdown、TXT 等文本格式
- 自动提取文本、切分知识片段并建立检索索引

### 3. 班级知识检索

- 基于 SQLite FTS5 实现全文检索
- 支持关键词查询课程资料
- 返回相关原文片段、资料来源及行号
- 支持资料名称筛选和检索结果排序

### 4. 智能知识问答

- 基于 RAG 技术实现课程知识问答
- 使用课程资料作为大语言模型的参考内容
- 回答附带引用来源，便于核验
- 当知识库缺少相关内容时给出提示，减少无依据的回答

## 二、技术栈

| 模块 | 技术 |
|------|------|
| 后端 | Python、Flask |
| 前端 | HTML、CSS、JavaScript |
| 数据库 | SQLite |
| 全文检索 | SQLite FTS5 |
| 智能问答 | RAG、智谱 GLM API |
| 身份认证 | JWT、Bearer Token |
| 自动化测试 | Pytest |
| 部署 | Docker Compose |

## 三、本地运行

### 1. 获取项目代码

```bash
git clone <仓库地址>
cd CampusClaw
```

### 2. 创建虚拟环境

```bash
python -m venv .venv
```

激活虚拟环境：

Windows：

```bash
.venv\Scripts\activate
```

macOS / Linux：

```bash
source .venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 配置环境变量

根据项目实际配置文件设置运行参数及大语言模型 API Key。

请勿将真实 API Key 提交到 Git 仓库。

### 5. 启动项目

根据项目实际入口文件启动 Flask 服务。

启动后，在浏览器中访问本地服务地址。

> 注意：具体启动命令、端口及环境变量名称将在项目代码确定后补充。

## 四、系统工作流程

1. 教师登录系统并上传课程资料。
2. 系统提取资料正文，切分知识片段并建立全文检索索引。
3. 学生登录后输入课程相关问题。
4. 系统根据用户所属班级检索相关知识片段。
5. 大语言模型结合检索结果生成回答。
6. 系统返回回答及引用来源，供学生查看和核验。

## 五、后续扩展计划

### 1. 多格式资料处理

- 增加 PDF、Word 文档的文本提取与索引
- 支持课程主题、章节等分类信息
- 支持资料预览、更新及索引同步重建

### 2. 检索与问答体验优化

- 支持按资料名称、章节和上传时间组合筛选
- 支持查看引用片段上下文及原文定位
- 增加答案反馈功能

### 3. 学习辅助功能

- 根据课程资料生成知识点摘要和复习提纲
- 自动生成自测题
- 支持收藏重点资料和问答结果
- 记录自测结果与错题

### 4. 教学统计与管理

- 统计热门检索词和常见问题
- 分析课程资料访问情况
- 通过图表展示班级知识点关注度
- 仅展示班级范围内的汇总数据

以上功能将根据项目开发进度逐步实现。

## 六、测试与部署

项目计划使用 Pytest 对以下功能进行自动化测试：

- 用户身份认证
- 班级权限隔离
- 课程资料上传与管理
- 全文检索
- 智能问答接口

部署方面计划使用 Docker Compose 统一开发与运行环境，并提供健康检查接口。

具体测试命令与部署步骤将在相关功能完成后补充。

## 七、项目说明

本项目为课程小组实践项目，基于已有班级知识库原型进行功能完善与扩展。

项目重点在于将课程资料管理、全文检索和大语言模型问答相结合，实现具有来源追溯能力和班级数据隔离机制的智能学习辅助系统。
