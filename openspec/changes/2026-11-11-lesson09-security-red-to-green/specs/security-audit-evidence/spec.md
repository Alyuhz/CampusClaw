# Spec Delta

## Purpose

为当前班级知识库落实第九课可复测的安全边界和交付证据，让组员能独立重放真实检查，辨别已通过的运行结果、条件不适用与尚需外部执行的事项。

## ADDED Requirements

### Requirement: 七列持久日志
系统 SHALL 持久保存七列单行 JSON，转义截断且不记秘密，拒绝也记；教师 MUST 仅查本班，学生 403。

#### Scenario: 七列持久日志复测
- **前置条件**：隔离数据与两个班教师/学生身份，固定场景与提交。
- **WHEN / 操作**：学生写入被拒，教师按学生时间窗查日志并故障注入
- **THEN / 可观测结果**：一条对应 403 记录，字段完整；跨班不泄露、学生不可查；审计故障写入回滚。

### Requirement: 实验与真实证据
交付 SHALL 包含固定三段式前后对照、四步实验、基线、门禁红绿与评审；替身/真实和待人工项 MUST 区分。

#### Scenario: 实验与真实证据复测
- **前置条件**：隔离数据与两个班教师/学生身份，固定场景与提交。
- **WHEN / 操作**：重放恶意模型四步并用学生身份触达写入执行层
- **THEN / 可观测结果**：前三步记录真实替身现象；第四步 403、数据不变且有日志。未执行真实模型或人工评审不得计完成。
