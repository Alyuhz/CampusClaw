# Spec Delta

## Purpose

为当前班级知识库落实第九课可复测的安全边界和交付证据，让组员能独立重放真实检查，辨别已通过的运行结果、条件不适用与尚需外部执行的事项。

## ADDED Requirements

### Requirement: 默认认证与角色
系统 SHALL 默认保护 API，读取当前有效服务端身份；无/非法/过期/吊销令牌为 401，学生教师写入为 403。

#### Scenario: 默认认证与角色复测
- **前置条件**：隔离数据与两个班教师/学生身份，固定场景与提交。
- **WHEN / 操作**：重放全部受保护接口并新增未装饰 API
- **THEN / 可观测结果**：匿名均 401；health 200，学生写 403 且三类业务数据无变化。

### Requirement: 逐资源与底层授权
系统 SHALL 对详情做单行归属检查，FTS/LIKE 均限定班级；写入事务 MUST 重新校验身份、教师角色与归属。

#### Scenario: 逐资源与底层授权复测
- **前置条件**：隔离数据与两个班教师/学生身份，固定场景与提交。
- **WHEN / 操作**：换班查详情/检索，再绕路由直接写入
- **THEN / 可观测结果**：跨班与不存在详情同体 404，B 两条检索为空；无身份 401、学生 403、跨班 404 且无残留。
