# Spec Delta

## Purpose

为当前班级知识库落实第九课可复测的安全边界和交付证据，让组员能独立重放真实检查，辨别已通过的运行结果、条件不适用与尚需外部执行的事项。

## ADDED Requirements

### Requirement: 资产与密钥历史
系统 SHALL 扫描工作树及本地引用历史并阻断命中；真实泄露 MUST 先轮换再清历史，不在证据中回显值。

#### Scenario: 资产与密钥历史复测
- **前置条件**：隔离数据与两个班教师/学生身份，固定场景与提交。
- **WHEN / 操作**：使用已删除环境密钥的隔离历史夹具重放扫描
- **THEN / 可观测结果**：扫描为非零且不回显值；真实仓库另有实际扫描报告。

### Requirement: 依赖审计与门禁
make check-security SHALL 扫描两份锁文件并阻断未登记漏洞、过期/错配例外和工具不可达；例外 MUST 含包版本编号理由缓解责任人与到期日。

#### Scenario: 依赖审计与门禁复测
- **前置条件**：隔离数据与两个班教师/学生身份，固定场景与提交。
- **WHEN / 操作**：运行真实门禁与隔离风险红绿实验
- **THEN / 可观测结果**：第一次非零、第二次零；真实依赖报告可复核，门禁输出带提交号，异常不算通过。
