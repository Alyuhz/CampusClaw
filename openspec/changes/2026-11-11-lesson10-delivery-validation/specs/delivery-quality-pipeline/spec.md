# Spec Delta

## Purpose

把现有班级知识库的测试场景与可重复命令连成一致的交付门禁，让本地与持续集成用同一判据阻断错误，并通过真实输出和来源信息复核构建，避免将本地模拟当作远端流水线成功。

## ADDED Requirements

### Requirement: 命令与场景追溯
交付 SHALL 列出可复跑命令、最后实测时间和覆盖场景；可自动化适用场景 MUST 至少对应一个实际可收集的测试，缺失业务另列差异。

#### Scenario: 逐场景定位用例
- **前置条件**：既有归档与第九课活动规约、本课新规约可读
- **WHEN / 操作**：生成追溯矩阵并对照测试收集清单
- **THEN / 可观测结果**：可自动化适用场景未覆盖数为0；每条有场景ID、测试nodeid、命令、最后结果与时间；不存在的教学技能/异步不能计绿。

### Requirement: 双门禁一致与故意改坏
本地与 CI SHALL 分别运行相同 make check 和 make check-security；任一失败 MUST 阻断镜像构建。红绿实验 SHALL 真正修改隔离副本中的断言并保留恢复证据。

#### Scenario: 故意坏断言被拦
- **前置条件**：隔离副本与工作区摘要已固定
- **WHEN / 操作**：改错一个明确断言、运行 make check，然后恢复原内容运行同命令
- **THEN / 可观测结果**：首次非零且输出定位到该断言，恢复后退出0；两次完整输出、文件差异与版本可查，不把缺环境失败当作坏提交证据。

#### Scenario: 安全门禁失败阻断
- **前置条件**：可复用现有安全夹具
- **WHEN / 操作**：模拟未登记漏洞或审计不可达后运行双门禁
- **THEN / 可观测结果**：安全命令非零，构建步骤不运行；全部通过才构建，不能放宽已有安全反例。

### Requirement: 镜像来源可追溯
镜像 SHALL 记录完整源提交和镜像摘要；本地未提交构建 MUST 明示工作区摘要，不得仅以基线 SHA 假装源码已提交。

#### Scenario: 本地与远端证据区分
- **前置条件**：本地有未提交变更，远端运行尚无记录
- **WHEN / 操作**：本地构建并检查标签；后续由外部实际触发 CI
- **THEN / 可观测结果**：本地标识含 dirty/worktree 摘要；远端只有真实 run ID、完整提交SHA和镜像摘要齐全才判通过，不能用本地执行替代。
