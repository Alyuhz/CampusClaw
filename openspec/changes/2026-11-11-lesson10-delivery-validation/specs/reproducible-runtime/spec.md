# Spec Delta

## Purpose

使现有 SQLite 课程知识库在干净目录中凭明确配置启动，并在数据库未就绪时拒绝接流量。通过应用代码的可验证打包边界、外置配置和持久数据验证，形成与现有技术栈一致的运行交付合同。

## ADDED Requirements

### Requirement: 干净目录启动与持久化
完成 README 预配置后，系统 SHALL 通过 docker compose up -d 启动默认应用及其所需资源，不依赖口头说明；数据 MUST 在重启后保留。

#### Scenario: 换目录启动
- **前置条件**：独立临时目录、独立项目名/卷、按README填好本机配置
- **WHEN / 操作**：执行 docker compose up -d 并完成登录上传、重启后读取
- **THEN / 可观测结果**：180秒内 ready；上传201、重启后资料可读、换班同体404；没有复用原开发数据库。

### Requirement: 就绪故障不接流量
系统 SHALL 提供无需业务身份的就绪状态；必要数据库不可读或迁移未完成 MUST 为503。

#### Scenario: 数据库故障
- **前置条件**：健康实例及隔离故障注入条件
- **WHEN / 操作**：使必要数据库检查失败并访问就绪探针
- **THEN / 可观测结果**：就绪从200变503、恢复后200；Compose健康反映故障，不能用健康接口伪造成功。

### Requirement: 应用打包与环境外置
最终运行镜像 MUST 不含应用业务 .py 明文、测试、构建工具、开发依赖或秘密；所需模板/静态/提示词/迁移资源 SHALL 完整可用。

#### Scenario: 扫描并启动打包产物
- **前置条件**：应用字节码产物与多阶段镜像已构建
- **WHEN / 操作**：扫描最终文件系统及保存层，再运行接口/页面/迁移检查
- **THEN / 可观测结果**：应用包无.py，资源齐全、非root、服务可用且秘密扫描无命中；标准库/第三方依赖与二进制扫描范围明示，不宣称全镜像无任何源码。
