# Proposal

## Why

### 为什么
当前项目已具备可重复的功能/安全门禁和镜像验证，但缺少场景追溯、运行观测、同参数压测改进及最终报告链路。第十课将这些已有能力收口为可复核的交付流水线，避免只有模板、缺少实际运行证据。

## What Changes

### 本次做到哪
- 盘点命令和最后实测时间，建立场景到可执行用例的追溯矩阵；功能与安全门禁保持本地/CI 同命令，隔离副本故意改坏断言后真实红→绿。
- 保留 SQLite/FTS5 与同步问答，完善 Compose 一键启动、只读就绪探针、多阶段应用字节码打包与镜像来源标识；运行镜像不含业务 Python 明文源文件与构建工具。
- 扩充 CI 为双门禁后构建镜像，实际远端构建编号与提交来源作为外部验收项；本地工作区使用基线与文件摘要，不能冒充已推送提交。
- 观测三个真实能力：资料上传、知识检索、带出处问答，展示调用量、错误率、P95 与当前执行中请求数；持久聚合避免多 worker 漏计。告警真实触发并送达本地测试接收器。
- 同脚本同参数对上传/查询/检索压测，以班级隔离且写后失效的检索缓存作为至少一项改进；保留前后原始样本、吞吐/P95/错误率与饱和点判定。
- 补手机浏览器同步流程验证、三位真实使用者反馈的记录/去向、七类 AI 核查规则、高风险三查、三份本课评审和根 report.md。

### 适配边界

| 原课表要求 | 本项目采用的适配 | 保留的原版差异 |
|---|---|---|
| 应用/MySQL/Qdrant | 应用+SQLite 持久卷；观测组件使用可选 profile | 不迁移数据库或引入未使用向量库 |
| 四个教学技能行为、三个技能曲线 | 追溯当前上传/检索/问答，真实复测跨班检索为空；工程 skills/ 不冒充业务技能 | 解题引导、教师改分、错题讲解不存在 |
| 作业202/任务状态/队列深度 | 同步上传201、查询/问答200、跨班404；显示执行中请求 | 不新增异步任务，不伪造 pending/running/succeeded 或队列指标 |
| 真实负责人通知 | 本地告警接收器真实收到通知并留证 | 真实外部负责人渠道另待配置与验证 |
| 推送构建/保护主干 | CI 配置与本地同命令验证，提交来源合同 | 远端设置与实际工作流运行仍需独立外部证据 |

### 本次不做
不补建批改、教学技能、异步消费者或向量检索，不伪造三人反馈、手机实机、远端运行、提交编号或负责人已获通知。应用字节码交付不等同整个 Python 运行环境无源码，也不保证不可逆向；第三方依赖与标准库另列范围。

### 与既有约定
保持班级从服务端记录取得、SQL 仅 db.py、统一 API、一次性 CSRF 与七列审计。第九课未提交实现是本次依赖基线，不修改其历史证据；新增记录用 reports/lesson10/ 隔离并在规定根报告追加索引。

## Capabilities

### New Capabilities
- `delivery-quality-pipeline`：命令盘点、场景追溯、双门禁红绿和来源可查的构建合同。
- `reproducible-runtime`：干净目录 Compose、应用字节码打包、就绪与密钥外置。
- `capability-observability`：三个现有能力的持久指标、图表和真实本地告警送达。
- `repeatable-performance`：隔离压测、班级安全缓存和同条件改进验证。
- `acceptance-evidence`：H5 验证、真实反馈、七类核查、高风险评审与最终结论索引。

### Modified Capabilities
无。主规约清单为空；沿用已检查的第九课活动规约，不另建近义安全规约。

## Impact

实施涉及 Makefile/CI、Dockerfile/Compose、HTTP/持久层/检索缓存、只增迁移、观测与压测脚本、规则及交付文档。修改受约束文件的原因是建立课堂交付门禁，验证方式为严格规约校验、功能/安全/冷启动/告警/前后压测，保留人工复核。规划阶段仅生成本变更文件。
