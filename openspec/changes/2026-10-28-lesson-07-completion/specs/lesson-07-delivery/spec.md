## Purpose

为 CampusClaw 第 7 课交付提供可测试的外部配置、结构化日志、界面状态、写请求语义和
失败路径基线，使克隆后的启动与验收不依赖开发机默认值或口头说明。

## ADDED Requirements

### Requirement: 应用配置必须全部外置

应用 SHALL 只从环境或显式测试配置读取版本、数据库、认证、模型和运行限额；除可选的
`GLM_API_KEY` 外，任一必填键缺失时 MUST 在监听端口前失败。`.env.example` SHALL 只包含
键名和空值。

#### Scenario: 缺少必填配置时拒绝启动

- **WHEN** 启动环境缺少 `GLM_MODEL`、`MAX_UPLOAD_BYTES` 或任一认证配置
- **THEN** 应用在监听端口前以非零状态退出，错误信息指出缺失的环境变量名

#### Scenario: 示例配置不包含值

- **WHEN** 检查 `.env.example` 的每个赋值
- **THEN** 每个值均为空，且所有应用读取的配置键都可从示例中找到

### Requirement: 请求日志必须是可关联的单行 JSON

每个应用请求 SHALL 恰好产生一条单行 JSON 访问日志，包含 UTC 时间、级别、模块、
`request_id`、方法、路径、状态码和耗时。框架 MUST NOT 再输出重复的纯文本访问日志。

#### Scenario: 健康检查产生结构化日志

- **WHEN** 客户端请求 `/health`
- **THEN** 响应带 `X-Request-ID`，请求日志只有一行 JSON，且 `request_id` 与该响应头一致

### Requirement: 数据视图必须表达四种状态

资料列表、检索结果和问答视图 SHALL 分别表达加载中、正常、空和错误状态。上传请求
进行期间 MUST 禁用提交控件；前端锁档只用于交互防误触，不得被描述为服务端幂等实现。

#### Scenario: 检索无结果

- **WHEN** 当前班没有匹配当前查询词的切片
- **THEN** 页面显示“资料中未找到相关内容”，而不是空白区域

#### Scenario: 请求进行中阻止重复操作

- **WHEN** 用户提交登录、上传、检索或问答请求且响应尚未返回
- **THEN** 对应按钮被禁用，完成后恢复可用

### Requirement: 写接口必须声明幂等语义

API 文档 SHALL 为每个写接口声明幂等性、重复调用效果和是否存在幂等键。没有服务端
幂等实现的接口 MUST 明确标记为非幂等。

#### Scenario: 重复上传的语义可查询

- **WHEN** 开发者阅读 `POST /api/v1/materials` 的 API 文档
- **THEN** 文档说明两个相同请求会创建两份资料，且当前不使用幂等键

### Requirement: 失败路径必须稳定且可观测

系统 SHALL 覆盖参数非法、无权限、资源不存在或跨班、依赖不可达四类失败。跨班与不存在
资料的响应体 MUST 逐字节一致；依赖不可达时 MUST 返回稳定错误，不得返回编造引用。

#### Scenario: 参数非法

- **WHEN** 客户端向检索接口提交空查询词或超出范围的 `limit`
- **THEN** 返回 400、`code=1101`，不执行全量检索

#### Scenario: 无权限

- **WHEN** 学生调用教师资料上传接口
- **THEN** 返回 403、`code=1204`，资料数量不变化

#### Scenario: 资源不存在或跨班

- **WHEN** 当前班用户读取其他班资料 ID 或不存在的资料 ID
- **THEN** 两者均返回 404、`code=1304`，响应体逐字节一致

#### Scenario: 依赖不可达

- **WHEN** 已配置 GLM 但模型服务超时或不可达
- **THEN** 返回 503、`code=1500`，且响应不包含引用或伪造答案
