## 当前规则

- 必须通过状态检查 `check`，且分支必须基于最新 `main`；
- 至少 1 名他人批准，新推送后旧批准失效，最后一次推送需再次批准；
- 管理员同样受规则约束；
- 只允许线性历史；
- 禁止强推和删除；
- 必须解决全部会话。

返回 200；此前同一接口返回 `404 Branch not protected`。

重写历史伪造为已满足。
