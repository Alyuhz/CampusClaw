# 真实使用者反馈

当前真实使用者：0/3。自动化移动视口和测试替身不计为真实使用者，没有代填意见。

每位真实使用者实际操作后填写一条：

| 字段 | 填写要求 |
|---|---|
| 匿名使用者标识/日期 | 本人实际使用后填写，避免真实姓名等多余个人信息 |
| 会话标识 | 脱敏审计event_id或另建匿名关联码；不要填写JWT/Cookie |
| 触发接口 | 实际方法和路径 |
| 观察到的返回 | 实际状态码、脱敏结果 |
| 预期与实际差异 | 本人观察，不把AI模拟意见当反馈 |
| 处理去向 | tasks.md新增任务与用例，或明确不做理由 |
| 复核证据 | 记录/截图/日志位置，脱敏 |

待实际收集三条后再填写记录。新缺陷先补可重复失败用例，再修复；本文件存在不代表真实反馈验收通过。
