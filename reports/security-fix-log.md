## SEC-01-A：默认身份边界

- **前置条件**：隔离数据库，固定教师/学生会话；匿名、非法、已过期、已吊销四种身份。
- **操作**：逐项请求 me、materials 列表/详情/上传、search、ask、logout、audit-logs、auth/csrf，另注册未装饰的新 API；公开 health 对照。
- **可观测结果**：预期受保护请求全 401、health 200；首次新 API 200，当前全矩阵 401、新 API 401。已有日志与业务表无未经授权写入。
- 证据：tests/test_security.py 的 test_sec01_matrix 与 test_new_api_defaults_to_denied；提交 e42b902 + 工作区摘要。

## SEC-02-A：资源与双检索

- **前置条件**：class-a 有唯一关键词资料，class-b 无该词。
- **操作**：B 查 A 的 ID 与不存在 ID，A/B 查同一词；强制 FTS 空以重放 LIKE；伪造 class_id 不能扩大权限。
- **可观测结果**：预期与当前为同体 404；A 两路径各 1 命中，B 两路径 []。首次详情场景已绿，没有制造红项。
- 证据：tests/test_api.py、test_sec02_both_search_paths、evidence/demo.json；提交 e42b902 + 工作区摘要。

## SEC-04-A：绕过路由
